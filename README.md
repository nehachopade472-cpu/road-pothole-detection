# Road Pothole Detection and Location Tracking
This project detects potholes in roads using a camera and YOLOv8 deep-learning model. The detected pothole location can be obtained using an ESP32 with NEO-6M GPS, and an alert containing the location can be sent to the concerned authority.
Technologies:Python,YOLOv8,OpenCV,ESP32,NEO-6M GPS, Computer Vision, SMTP/Email
